# Documentation

This is the official codebase documentation of Guitar Dream Engine.

- [legal.md](legal.md): what never goes into this repo, and why
- [contributing.md](contributing.md): branches, commits, pull requests
- [release-process.md](platform/release-process.md): how a game is released
- [adding-a-game.md](platform/adding-a-game.md): starting a new game folder and its `game-info.yaml`
- [guidelines/](guidelines/): the owner's general
  guidelines, the universal launcher rules (GAMEPADS screen, Enhanced menu,
  mouse, packaging; gd-game-01 is the reference) and the behaviours every game shares
- [tasks/gd-backlog.md](tasks/gd-backlog.md): the single backlog (read it before working;
  update it at the start and end of every task)
- [spikes/](spikes/README.md): studies and spikes (platforms, signing, stores, HDR)

Elsewhere: each game's `README.md`, `docs/` and `CHANGELOG.md`; the engine
codebase in `gd-engine-docs/`; the launcher in `gd-engine-launcher/`.
