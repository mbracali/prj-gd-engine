# Guitar Dream Universal Launcher

Play the Guitar Dream Engine games from your own disc images, all from one
window.

1. Put your disc images (`.iso`) in `original_isos/`, or drop one onto the
   launcher's window, or use **Load ISO** on a game's row.
2. Pick a lit (green) game and press **Play**. Quit the game to come back to
   the list.

The user manual is in `manual/`. The Guitar Dream Engine is a reimplementation:
it contains no game data, and you need your own original discs.
