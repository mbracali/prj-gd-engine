# original_isos/

Put the disc images (`.iso`) of your own original games here. The launcher
looks at every `.iso` in this folder when it starts, recognises which game
each one is by its content (the file name does not matter), and lights that
game up in the list.

Supported now: Guitar Hero (PlayStation 2, USA) and Guitar Hero II (Xbox 360,
USA). You can also keep your discs anywhere else and drop them onto the
launcher's window, or use Load ISO: the launcher then remembers where they are.
